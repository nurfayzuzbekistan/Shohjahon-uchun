# 😎 Shohjahon 2.0 ❤️

> 🎁 Shohjahon uchun maxsus tayyorlangan interaktiv mini-sahifa!

Bu loyiha oddiy HTML sahifadan ko‘ra biroz qiziqroq. Unda animatsiyalar, iliq gaplar, yashirin tugma va maxfiy **Easter Egg** mavjud. 🔐🥚

## ✨ Xususiyatlari

* 💙 Shohjahon haqida iliq va do‘stona gaplar
* ❤️ Animatsiyali yurakchalar
* ✨ Chiroyli gradient fon
* 🎨 Glassmorphism dizayn
* 🔄 Har bosilganda yangi gap
* 🌙 Rejimni o‘zgartirish tugmasi
* 🔐 Yashirin maxfiy tugma
* 🎁 Maxfiy xona
* 🥚 Yashirin Easter Egg
* 📱 Telefon va kompyuterga mos dizayn
* ⌨️ `Escape` tugmasi bilan maxfiy oynalarni yopish
* 🚀 Hech qanday kutubxona yoki framework talab qilmaydi

## 🥚 Easter Egg

Saytda **2 ta maxfiy funksiya** bor:

### 🔐 1. Maxfiy tugma

Pastki o‘ng burchakdagi kichkina `🔒` tugmani toping.

### 🥚 2. Yashirin Easter Egg

`Shohjahon ❤️` yozuvini **5 marta** bosing.

😎 Agar topsangiz, maxfiy xabar chiqadi!

Agar GitHub Pages yoqilgan bo‘lsa, loyihani internet orqali ham ochish mumkin.
